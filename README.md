# TG Personal Automation Bot
Telegram-бот для автоматизации личных задач.

Проект разрабатывается как единая платформа для различных автоматизаций.
На данный момент реализован модуль мониторинга новых заказов на Kwork с отправкой уведомлений в Telegram.

## Текущие возможности
- Мониторинг новых заказов в рубрике "скрипты и чат-боты" на Kwork
- Отправка уведомлений в Telegram
- Управление парсингом через Telegram

## Требования
- `pip install -r requirements.txt`
- Создать `.env`-файл для хранения переменных окружения `BOT_TOKEN` и `ADMIN_ID`

## Пример .env-файла
```
BOT_TOKEN="your_bot_token"
ADMIN_ID="your_tg_id"
```

## Запуск
```bash
python main.py
```

## Используемые технологии
- python
- aiogram
- requests
